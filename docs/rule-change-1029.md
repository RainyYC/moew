# 2026-10-29 规则变化：网格放松为 V·P ≤ R、共享专家解耦

两条改动都会改变最优值，**第一条扩大可行域，第二条放松依赖**。

## 1. 网格：`V·P = R` → `V·P ≤ R`

允许有空闲卡：用了 `V·P` 张，剩下 `R − V·P` 张不参与本步（等价于数据并行副本，不影响单步 ``Time``）。

**直接后果**：`V` 与 `P` 解耦。以前 `V = R/P` 被钉死，现在 `V ∈ [1, min(L, 64, R//P)]`。
既然卡是"免费"的，加 `V` 只会让每个卡组少背几层（`lb` 下降），代价是填充项
`(nmb+V-1)/nmb` 略增；两者的乘积 `(nmb+V-1)/V` 对 `V` 单调递减 ⇒ **取最大的 V**。
于是每个 `P` 只剩一个候选 `V = min(L, 64, R//P)`，搜索空间反而更小。

最赚的是大 `R` 小 `P`：`R=512, L=64` 时 `P=1, V=64` 只用 **64/512 张卡**，但 `x=0`
（单 rank 无 EP 对端）⇒ **通信完全消失**，只剩计算。

| 用例 | 旧（P=8, 用满 512 卡） | 新（P=1, 用 64 卡） | 倍数 |
| --- | --- | --- | --- |
| b01-loose | 9.48e14 | **6.89e12** | 137× |
| b05-maxmb | 6.10e15 | **5.00e13** | 122× |

代价是每卡驻留更多专家：`Mexp = L·E·Z/R`（与 P 无关，只由 `V` 决定 `Zs` 项），
所以能不能取 `P=1` 取决于 `M`。

## 2. 共享专家：可与同层其余部分重叠

`DEPS` 的变化（`s` / `s_bwd` / `s_dw` 三个共享专家操作）：

| 操作 | 旧前驱 | 新前驱 |
| --- | --- | --- |
| `disp` | `s` | **无**（只保留跨层的"上一层 `comb`"） |
| `comb_bwd` | `s_bwd` | **本层 `comb`**（反向链的头，不再穿过共享专家） |
| `s_bwd` | `comb` | `s` + `comb`（自己的前向 + 本层前向完成） |
| `s_dw` | `comb_bwd` | **`s_bwd`**（只等自己的输入梯度） |

跨层锚点相应补上，否则会出现"反向早于前向"这种假解：

- `disp(ℓ) ≥ comb(ℓ−1)`（原来这条是通过 `disp ≥ s ≥ comb(ℓ−1)` 传递的）；
- `comb_bwd(ℓ) ≥ disp_bwd(ℓ+1)`（原来通过 `comb_bwd ≥ s_bwd ≥ disp_bwd(ℓ+1)` 传递）。

**踩过的坑**：一开始只删了层内边、忘了补跨层锚点，`comb_bwd` 于是没有任何前驱，
CP-SAT 直接给出 `ex2 = 3200`、`ex3 = 4000`（都等于通信引擎下界）——看着像"大幅优化"，
其实是模型退化。补上锚点后回到 `4880 / 6072`。**凡放松依赖，必须重查"因果是否还能传递"。**

## 3. 六例新最优（CP-SAT 证明）

| 用例 | 题面样例 | 旧规则最优 | **新规则最优** | 变化 |
| --- | --- | --- | --- | --- |
| ex1 | 592 | 576 | **560** | −16 |
| ex2 | 4880 | 4880 | 4880 | 0 |
| ex3 | 7000 | 6072 | 6072 | 0 |
| ex4 | 3200 | 3200 | 3200 | 0 |
| ex5 | 416 | 416 | **368** | −48 |
| ex6 | 1744 | 1744 | **1696** | −48 |

ex2 / ex3 没变，是因为它们的 `F_s = 0`（`s=0`），共享专家本来就不占时间。
ex1 / ex5 / ex6 的收益正好是 `s` 被藏起来的量。
