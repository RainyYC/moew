# C++ 编码规范

提交源码为自包含的 C++17 单文件 `src/solver.cpp`。标准库头文件必须显式列出，不使用项目本地 `#include`。统一使用四空格缩进、每行约 100 列、控制语句加花括号、一行一条语句，并遵循仓库 `.clang-format`。

类型使用 `PascalCase`；函数、方法、局部变量及成员使用 `snake_case`。为便于核对题目公式，`P`、`V`、`L` 等问题域符号可保留原样，并在不直观处就近说明。按功能将代码分成清楚的区域，把输入解析、搜索阶段和输出等职责放进具名函数。注释记录约束、精确语义和比较规则，不复述显然的语法。

所有运算保持精确整数语义，包括有符号 128 位计算。内存检查遵循官方闭区间：区间端点相接时仍然重叠。若某组所有通信时长均为零，该组通信 buffer 不计入内存。候选仅在 `Time` 严格下降时替换；local polish 允许 `Time` 相等且操作结束时间总和下降时移动。重构必须保持遍历顺序、比较/tie 规则、命令行语义及既有截止时间。
